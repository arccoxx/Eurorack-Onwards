# Art theory and technique — grid of 42 metadata records

Database: `art-theory-synthesis-grid.json` (42 records). Full texts are not in the repository. The source package said JSTOR full text was not bulk-downloaded. Records point at Project Gutenberg, Internet Archive, a few open PDFs or DOIs, and JSTOR landing pages.

## How the records were made

The t472 pass filtered a local public-domain catalog for tags such as techne, form, mimesis, and perception, then added a small number of open-web or JSTOR-metadata rows. This release kept the metadata, dropped local text paths, and set `fulltext_redistributed` to false.

## Vitality axes (a working table, not a measurement)

| Axis | Lower | Higher |
|---|---|---|
| Reproducibility | Oral only | Scores, schematics, patch notes, code |
| Teachability | Apprenticeship only | Exercises someone else can run |
| Combinatorial openness | Closed canon | Recombination |
| Instrument coupling | Medium-agnostic slogans | Constraints of a real machine |
| Feedback | One-shot object | Iterative correction |

## Exposure hypotheses

These are hypotheses, not findings. Guild technique can stay oral while print treatises publish recipes that academies still gate. Cold-war electronic studios were institutional. Open schematics coexist with copyrighted module firmware. Language models make descriptions common and do not by themselves transmit hands-on skill.

A falsifier for any row is a case study that shows the opposite exposure pattern. The table is not that case study.

## Gaps

Music-specific open articles are thin in this 42. The grid is a finding aid, not a conclusion that “synthesis was secret” or “synthesis was public.”
